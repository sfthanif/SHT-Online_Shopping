# SHT Online Shopping (scaffold)

This repository contains a starter scaffold for a premium e-commerce site using Next.js (frontend) and Express + MongoDB (backend).

Quick start:

1. Copy environment file:

```bash
cp .env.example .env.local
```

2. Install root dev tooling and workspace packages:

```bash
npm install
cd frontend && npm install
cd ../backend && npm install
```

3. Run both services in development (from repository root):

```bash
npm run dev
```

This scaffold includes a minimal Next.js frontend with Tailwind and a simple Express API with Mongoose models. Expand routes, authentication, payments, and UI components according to the project plan.
